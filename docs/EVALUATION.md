# 评测能说明什么

目前使用有限规则测试和已经缓存的候选复验。没有全库数学强弱金标准。

上一轮固定的 99 对候选包含 97 对同篇版本和 2 对跨论文线索。旧版留下的 93 对未分类变化，当前有 4 对定位到新增属性或条件词面，7 对按完整有限规则过滤为改写，其余 82 对拆成具体的范围、量词、条件引用、公式指数/下标/宏等变化；整体数学强弱仍未认证。

旧门控排除项另检查 377 对。首批 281 对用于发现并修正规则缺口，随后固定的 96 对用于复验候选资格。最终补出 2 条可读线索，没有新增最高优先项。它们不是两个已确认的真实弱化事件。

所有这些数据都来自已有局部缓存。0/96 的新增合格候选数不等于零漏检；门后有范围文字也不等于真实漏检。作者姓名关联仍不是身份或原创归属认证。

本次来源迁移不重新执行检索或修改数学判定，核对的是原库寻址、具体版本绑定、真实行号、报告入口及旧证据恢复。数学核心的三个文件保持上一轮的字节哈希。

对这 476 对的 952 个来源端点，按需核对了 225 篇原库记录：595 个端点改为原库直读，357 个沿用历史或版本未绑定缓存。905 个声明可逐字匹配，38 个由唯一标签定位环境，8 个通过注释/空白规范后的唯一匹配定位；另 1 个新补齐全文的端点仍无声明坐标，明确保留该缺口。来源导航改善不代表候选数学方向得到认证。

公开测试采用合成文本；可在不持有真实全库和逐案标签的机器上运行。完整环境额外运行一个很小的 gzip 寻址测试。测试通过只说明这些有限行为受到了检查。
